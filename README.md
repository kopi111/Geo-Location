# GPS Employee Tracking API

Geolocation-based employee clock-in/out system with Clean Architecture.

## Features
- **GPS Verification**: Location-based clock in/out
- **Location Tracking**: Real-time employee positions
- **Clean Architecture**: Domain-Driven Design implementation
- **API Endpoints**: RESTful interfaces
- **Authentication**: Secure access control

## Technology Stack
- ASP.NET Core
- Entity Framework Core
- .NET
- SQL Server
- GPS/Geolocation services

## Use Cases
- Field employee tracking
- Time and attendance
- Location verification
- Workforce management
